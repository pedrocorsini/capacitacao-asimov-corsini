## Portfólio pessoal

O portfólio reúne minha apresentação, formação, habilidades e projetos nas seções
Home, Sobre Mim, Skills, Projetos e Contato.

O layout utiliza Flexbox na navegação e Grid na organização das seções. As media
queries ajustam as colunas, os espaçamentos e o alinhamento da navbar em telas menores.

As animações de entrada acompanham a rolagem com `animation-timeline: view()` e
respeitam a preferência de movimento reduzido. O botão de tema exibe uma lua no modo
escuro e um sol no modo claro. Um pequeno script em JavaScript alterna as cores e
salva a escolha no `localStorage`, mantendo o modo escuro como padrão.

O portfólio está publicado no GitHub Pages: [Acessar o portfólio](https://pedrocorsini.github.io/capacitacao-asimov-corsini/semana-02-html-css/portfolio/).

Para visualizar localmente, abra [portfolio/index.html](portfolio/index.html) no
navegador ou utilize a extensão Live Server do VS Code.
